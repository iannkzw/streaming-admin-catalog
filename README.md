  </p>

## Tecnologias Utilizadas

- **ASP.NET Core 8.0** - Framework web
- **Razor Pages** - Interface de usuário
- **Entity Framework Core** - Mapeamento objeto-relacional
- **Bootstrap** - Framework CSS para responsividade

## Funcionalidades

- Gerenciamento de categorias de vídeos
- CRUD completo (Create, Read, Update, Delete)
- Interface responsiva e intuitiva
- Validação de dados

## Como Executar

1. Certifique-se de ter o .NET 8.0 SDK instalado
2. Clone o repositório
3. Execute `dotnet run` na raiz do projeto
4. Acesse `https://localhost:5001` ou `http://localhost:5000`
